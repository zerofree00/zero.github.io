平时想下载一些歌曲，网上的在线工具要么广告多，要么不稳定。索性自己写了一个本地的搜索下载小工具，支持三个数据源，双击 bat 就能用。

## 三个数据源

| 数据源 | 格式 | 特点 |
|--------|------|------|
| 歌曲吧 (gequbao.com) | MP3 | 曲库全，下载稳定 |
| 鲸音无损音乐 (jywav.com) | MP3 + FLAC | 支持无损音质，有 LRC 歌词 |
| 泡椒音乐 (pjmp3.com) | 需手动 | 曲库丰富，有滑块验证需浏览器操作 |

## 使用方式

最简单的方式是双击 bat 文件：

- `gequbao.bat` — 歌曲吧搜索下载
- `jywav.bat` — 鲸音无损音乐搜索下载
- `pjmp3.bat` — 泡椒音乐搜索（浏览器打开）
- `点歌.bat` — 选择数据源

打开后输入歌名或歌手名，回车搜索，输入编号下载。输入 `0` 下载全部，`q` 退出。

也可以用命令行：

```bash
python gequbao_search.py "晴天" -d
python jywav_search.py "周杰伦" --flac -d
python pjmp3_search.py "稻香"
```

## 依赖

需要 Python 和两个包：

```bash
pip install requests beautifulsoup4
```

## 一些细节

- 文件名自动清理非法字符，不会出错
- 已存在的文件自动跳过，不会重复下载
- 每次下载间隔 0.5 秒，避免请求过快
- jywav 的 `--check` 参数可以检查音质，按 FLAC > MP3 > 网盘排序
- 如果某个网站挂了，换一个数据源就行

## 在线搜索

如果不想装 Python，也可以用这个在线搜索页面，直接在浏览器里搜索歌曲：[音乐搜索页](/zero.github.io/music-search.html)。

页面会展示搜索结果和原文链接，点击跳转到对应网站查看详情和下载。
