# 歌曲宝 - 歌曲搜索下载工具

支持多个音乐网站的搜索和 MP3/FLAC 下载。

## 文件位置

```
D:\code\tools\歌曲宝\
  ├── 点歌.bat              ← 双击运行（选择数据源）
  ├── gequbao.bat            ← 双击运行（歌曲吧）
  ├── jywav.bat              ← 双击运行（鲸音无损音乐）
  ├── pjmp3.bat              ← 双击运行（泡椒音乐，浏览器下载）
  ├── gequbao_search.py      ← 歌曲吧 (gequbao.com) 脚本
  ├── jywav_search.py        ← 鲸音无损音乐 (jywav.com) 脚本
  ├── pjmp3_search.py        ← 泡椒音乐 (pjmp3.com) 搜索脚本
  ├── 音乐下载工具说明.md      ← 本说明文件
  └── music\                 ← 默认下载目录
```

## 使用方法

### 方法一：双击 bat（最简单）

直接双击对应的 bat 文件：

| bat 文件 | 数据源 | 格式 |
|----------|--------|------|
| `点歌.bat` | 双击后选择数据源 | - |
| `gequbao.bat` | 歌曲吧 | MP3 |
| `jywav.bat` | 鲸音无损音乐 | MP3 + FLAC 无损 |
| `pjmp3.bat` | 泡椒音乐 | 浏览器手动下载 |

打开后：
1. 输入歌名或歌手名，回车
2. 看到结果后输入编号下载（`0` = 全部下载）
3. 继续搜索下一首，输入 `q` 退出

### 方法二：命令行

```bash
# === 歌曲吧 (gequbao) ===
python D:\code\tools\歌曲宝\gequbao_search.py "晴天"
python D:\code\tools\歌曲宝\gequbao_search.py "周杰伦" -d
python D:\code\tools\歌曲宝\gequbao_search.py "稻香" -d -o D:\Music

# === 鲸音无损音乐 (jywav) ===
python D:\code\tools\歌曲宝\jywav_search.py "晴天"
python D:\code\tools\歌曲宝\jywav_search.py "周杰伦" -d
python D:\code\tools\歌曲宝\jywav_search.py "稻香" -d --flac    # 优先无损格式
python D:\code\tools\歌曲宝\jywav_search.py "晴天" --check      # 检查音质，按质量排序
python D:\code\tools\歌曲宝\jywav_search.py "晴天" -d --check   # 检查音质 + 下载

# === 泡椒音乐 (pjmp3) ===
python D:\code\tools\歌曲宝\pjmp3_search.py "晴天"
python D:\code\tools\歌曲宝\pjmp3_search.py "周杰伦" -i          # 交互模式
python D:\code\tools\歌曲宝\pjmp3_search.py "稻香" --json        # JSON 输出
```

## 参数说明

两个脚本参数基本一致：

| 参数 | 缩写 | 说明 |
|------|------|------|
| `keyword` | | 搜索关键词（歌名或歌手名） |
| `--download` | `-d` | 下载歌曲 |
| `--output DIR` | `-o` | 指定下载目录，默认 `music` 文件夹 |
| `--all` | `-a` | 下载全部搜索结果 |
| `--limit N` | `-l` | 限制搜索结果数量 |
| `--interactive` | `-i` | 交互模式（不带参数时自动进入） |
| `--json` | | 以 JSON 格式输出 |
| `--flac` | | (仅 jywav) 优先下载 FLAC 无损格式 |
| `--check` | `-c` | (仅 jywav) 检查每首歌的音质，按 FLAC > MP3 > 网盘 排序，过滤无资源歌曲 |

## 三个数据源的区别

| | 歌曲吧 (gequbao) | 鲸音无损音乐 (jywav) | 泡椒音乐 (pjmp3) |
|---|---|---|---|
| 格式 | MP3 | MP3 + FLAC 无损 | 需手动下载 |
| 下载方式 | 脚本自动下载 | 脚本自动下载 | 浏览器打开页面 |
| 歌词 | 无 | 有 LRC 歌词下载 | 无 |
| 特点 | 曲库全，下载稳定 | 支持无损音质 | 曲库丰富，需手动操作 |

## 依赖

需要 Python 和两个包（已安装）：
```
pip install requests beautifulsoup4
```

## 注意事项

- 搜索结果同时会显示网盘链接，如果在线下载失败可以用网盘
- 文件名自动格式化，不会出现非法字符
- 已存在的文件会自动跳过，不会重复下载
- 每次下载间隔 0.5 秒，避免请求过快
- 如果某个网站无法访问，可以换另一个数据源试试
- jywav 的 `--check` 参数会自动过滤掉 CDN 链接过期的歌曲，音质好的排在前面
- pjmp3.com 有滑块验证码保护，脚本只负责搜索并打开浏览器，需要手动下载
